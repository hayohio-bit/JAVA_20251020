## OOP 4대 특성

- 캐플화 (Encapsulation) : 데이터 은닉
- 상속 (Inheritance) : 부모 클래스의 특성 계승
- 다형성 (Polymorphism) : 한 객체가 여러 타입을 가짐
- 추상화 (Abstraction) : 복잡한 구현 숨김

## 접근 제한자

- public : 모든 클래스에서 접근 가능
- protected : 같은 패키지 + 자식 클래스
- default : 같은 패키지만
- private : 같은 클래스만

## 컴렉션 (Collection)

- List : ArrayList, LinkedList (순서 있음)
- Set : HashSet, TreeSet (중복 불허)
- Map : HashMap, TreeMap (키-값 쌍)
- Queue, Stack

## 예외 처리

- try-catch-finally : 예외 처리 구문
- throw : 예외 발생
- throws : 메서드에서 예외 선언
- Exception : 컴파일 시점 체크 가능
- RuntimeException : 실행 시점 발생

## 기본 문법

- 클래스 선언 : public class ClassName {}
- 메인 메서드 : public static void main(String[] args) {}
- 변수 선언 : 타입 변수명 = 값;
- 상수 : final 타입 상수명 = 값;

## 데이터 타입

- 기본형 : byte, short, int, long, float, double, char, boolean
- 참조형 : String, Array, Class, Interface
- 형 변환 : 자동 형 변환, 강제 형 변환 (casting)

## 제어문

- 조건문 : if, else if, else, switch
- 반복문 : for, while, do-while, enhanced for
- 분기문 : break, continue, return

## 객체지향

- 클래스 : 객체를 생성하기 위한 템플릿
- 객체 : 클래스의 인스턴스
- 생성자 : 객체 초기화 메서드
- 메서드 : 클래스의 기능
- 필드 : 클래스의 속성
